Master Library Bridge 11-LIB-BRIDGE
▾
Loads your master product library from a Google Sheets CSV (preferred) or JSON URL. Auto-detects iPoint exports and translates them to the SFX schema — keep your iPoint dump fresh and the tool stays in sync. Caches in browser for 24 hours, auto-refreshes daily. Falls back to the hardcoded 263 if no URL is set or fetch fails.
Google Sheets: File → Share → Publish to web → pick tab → CSV → uncheck "Restrict access" → Publish → paste URL here.
JSON: Upload to Drive shared "anyone with link" → paste direct download URL.
Publish a second tab in your same Sheet (e.g., "SFX Rack Overrides") with engineering data iPoint doesn't track: shelf-mounted items, accurate rack heights, equipment that needs a shelf, etc.
Match column: Part Number (or part_number). Any other column overrides the iPoint value for that record.
📥 Fetch Now
Manually re-fetch the library from Drive. Useful when you've just updated the master sheet and want changes immediately.
🔄 Auto-refresh status
Refreshes automatically when the page is opened > 24 hours after last fetch.
